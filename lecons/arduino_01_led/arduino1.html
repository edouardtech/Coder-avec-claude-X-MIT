Partie 1

C'est quoi, Arduino ?

Arduino est une petite carte électronique, grande comme une carte bancaire. C'est un mini-ordinateur qu'on programme pour contrôler des objets : des LED, des moteurs, des capteurs, des robots… 🤖

La carte a des broches (en anglais pins), numérotées de 0 à 13. On y branche des composants. La broche 13 est spéciale : elle a déjà une petite LED soudée sur la carte.

Dans le simulateur de cette page, voici les LED que tu peux utiliser :

⚡
Avec une vraie carte, on branche toujours une LED avec une résistance (220 Ω par exemple), sinon elle grille. Le simulateur, lui, ne craint rien 😉
Partie 2

setup() et loop()

Tout programme Arduino a deux parties :

void setup() {
  // s'exécute UNE SEULE fois, au démarrage
}

void loop() {
  // se répète À L'INFINI
}
  • setup() : on prépare la carte (par exemple : « la broche 13 est une sortie »).
  • loop() : le cœur du programme. Quand il arrive à la fin, il recommence au début, pour toujours.
🔁
Tu connais déjà ça ! loop(), c'est exactement une boucle infinie, comme while True: en Python.
Partie 3

Les 3 instructions pour les LED

InstructionCe qu'elle fait
pinMode(13, OUTPUT);La broche 13 devient une sortie : elle peut envoyer du courant. À mettre dans setup().
digitalWrite(13, HIGH);Envoie du courant : la LED s'allume.
digitalWrite(13, LOW);Coupe le courant : la LED s'éteint.
delay(1000);Attend 1000 millisecondes, c'est-à-dire 1 seconde.

Le programme le plus célèbre du monde Arduino, le Blink (« clignoter ») :

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);   // allume
  delay(1000);              // attend 1 seconde
  digitalWrite(13, LOW);    // éteins
  delay(1000);              // attend 1 seconde
}

Arduino se programme en C++. Les idées sont les mêmes qu'en Python, seule l'écriture change :

Partie 5

Les variables et la boucle for

Une variable se déclare avec son type. Pratique pour changer la vitesse partout d'un coup :

int vitesse = 300;

void loop() {
  digitalWrite(13, HIGH);
  delay(vitesse);
  digitalWrite(13, LOW);
  delay(vitesse);
}

La boucle for en C++ s'écrit en 3 morceaux, séparés par des ; :

for (int i = 2; i <= 6; i++) {
  pinMode(i, OUTPUT);
}
  1. int i = 2 : départ, i commence à 2 ;
  2. i <= 6 : on continue tant que i est plus petit ou égal à 6 ;
  3. i++ : à chaque tour, i augmente de 1 (c'est un raccourci de i = i + 1).

C'est l'équivalent de for i in range(2, 7): en Python. Ici, ça configure les broches 2, 3, 4, 5 et 6 en une seule boucle !

Partie 6

Le moniteur série : le print d'Arduino

Pour afficher du texte (très utile pour comprendre ce que fait ton programme), on utilise le moniteur série :

void setup() {
  Serial.begin(9600);           // on démarre le moniteur (à faire une fois)
  Serial.println("Bonjour !");   // affiche et va à la ligne
}

Serial.print(...) affiche sans aller à la ligne. Sans Serial.begin(9600);, rien ne s'affiche.

Partie 8

Les erreurs classiques

  • Oublier le ; à la fin d'une ligne
  • Se tromper de majuscules : digitalwrite au lieu de digitalWrite
  • Oublier pinMode(…, OUTPUT); dans setup() → la LED ne s'allume pas
  • Oublier le delay après LOW → la LED s'éteint si peu de temps qu'on croit qu'elle reste allumée
